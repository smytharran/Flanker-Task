Flanker Task Experiment

Overview
This project is a command-line implementation of the Flanker Task, developed in Python using Object-Oriented Programming principles.
The application presents participants with five-letter strings and requires them to identify the middle character according to predefined response rules. The program records participant responses and tracks correct and incorrect answers throughout the experiment.
This project was completed as part of the CS2011 Object-Oriented Programming module at University College Cork and received a First Class Honours (1.1) grade.

Features
- Object-Oriented Python design
- File-based experiment configuration
- Dynamic loading of trial rounds from text files
- Participant consent handling
- Correct and incorrect response tracking
- Use of inheritance and method overriding
- Interaction between multiple classes
- Command-line user interface
